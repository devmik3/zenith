# Zenith

Zenith is a small MCP/ACP harness for running a coding agent as a multi-agent
orchestrator.

## Quick Run with Amp

Follow [Quick Start with Amp](../README.md#quick-start-with-amp) in the repository
README. It describes the Amp Orb arrangement, automatic launcher skill creation,
and use of Zenith's original workflow.

Amp runtime integration remains experimental; the startup instructions do not
establish worker compatibility by themselves.
